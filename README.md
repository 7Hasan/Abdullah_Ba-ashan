# صدقة جارية عن الفقيه عبدالله براهم باعشن

موقع تذكاري يضم القرآن والأذكار والدعاء وروابط نافعة، مع إمكانية تثبيته على الهاتف واستخدام محتوى الموقع الأساسي دون اتصال بعد فتحه مرة واحدة بنجاح.

**الموقع:** https://7hasan.github.io/Abdullah_Ba-ashan/

## الملفات

- `index.html` — محتوى الصفحة.
- `style.css` — التصميم والألوان والحركات الخفيفة.
- `script.js` — التفاعلات والتخزين المحلي وطلب التثبيت.
- `manifest.webmanifest` — إعدادات تثبيت الموقع كتطبيق.
- `sw.js` — تخزين ملفات الموقع الأساسية للعمل دون اتصال.
- `icon.svg` — أيقونة التطبيق.
- `Abdullah.jpg` — الصورة الأصلية.

## الحفظ والخصوصية

- عداد التسبيح وسجل الدعاء يُحفظان محليًا في متصفح الجهاز نفسه.
- سجل الدعاء ليس عامًا ولا يُرسل إلى Google Sheets أو أي خادم.
- يمكن استخدام الموقع الأساسي دون اتصال بعد تحميله أول مرة وتثبيت ملفات التخزين المؤقت.
- الروابط الخارجية والبحث عبر الإنترنت لا تعمل دون اتصال.
- حذف بيانات المتصفح أو استخدام جهاز/متصفح آخر قد يؤدي إلى فقد البيانات المحلية.

## تثبيت الموقع

- Android: افتح الموقع عبر Chrome، ثم قائمة المتصفح واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPhone: افتح الموقع عبر Safari، ثم «مشاركة» وبعدها «إضافة إلى الشاشة الرئيسية».
