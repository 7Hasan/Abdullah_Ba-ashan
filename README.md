# صدقة جارية عن الفقيه عبدالله براهم باعشن

موقع تذكاري يضم روابط للقرآن الكريم والأذكار والدعاء ومصادر نافعة، نسأل الله أن يتقبل هذا العمل وينفع به.

**الموقع:** https://7hasan.github.io/Abdullah_Ba-ashan/

## بنية المشروع

- `index.html` — هيكل الصفحة والمحتوى.
- `style.css` — التصميم والألوان والتجاوب مع الشاشات والأنيميشن الخفيف.
- `script.js` — التفاعلات والمشاركة والبحث وعداد التسبيح الشخصي.
- `Abdullah.jpg` — الصورة المستخدمة في الصفحة.

## الهوية البصرية

- أخضر زيتي: اللون الرئيسي.
- بيج: الخلفيات والمساحات الهادئة.
- نحاسي دافئ: اللمسات والتفاصيل.

> ملاحظة: عداد التسبيح يُحفظ محليًا على جهاز الزائر، ولا يمثل إحصاءً عامًا. لا توجد قاعدة بيانات أو خدمة خلفية لتجميع رسائل أو أعداد الزوار.
